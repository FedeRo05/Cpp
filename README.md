#  Cap Collection Manager - C++ Edition

Un sistema de gestión de inventario para coleccionistas de gorras desarrollado en **C++**. Este proyecto demuestra el uso de Programación Orientada a Objetos (POO) y el manejo de archivos para la persistencia de datos.

##  Características Principales

* **Gestión de Inventario:** Permite registrar gorras detallando marca, equipo y tipo de visera.
* **Persistencia de Datos:** Implementación de lectura y escritura de archivos (`fstream`), lo que permite que la colección se guarde automáticamente al salir y se cargue al iniciar.
* **Interfaz Dinámica:** Menú interactivo por consola con validación de flujo de datos.
* **Estructuras Eficientes:** Uso de `std::vector` para la gestión dinámica de memoria de los objetos.

##  Tecnologías y Conceptos Aplicados

Para este proyecto, me enfoqué en demostrar habilidades sólidas en C++ moderno:

1.  **Programación Orientada a Objetos (POO):** Uso de clases, encapsulamiento (atributos privados) y métodos públicos (Getters/Setters).
2.  **Manejo de Flujos (Streams):** Uso avanzado de `iostream` y `fstream` para la comunicación entre el software y el hardware (disco duro).
3.  **Memoria Dinámica:** Gestión de colecciones de tamaño variable mediante la librería `vector`.
4.  **Limpieza de Buffer:** Implementación de `getline` y `ws` para manejar entradas de texto con espacios, evitando errores comunes de entrada de datos en C++.
